# Neural Network Corrector for Explicit Euler Method in the Lotka–Volterra System

This repository contains the full codebase accompanying the paper:

**"Neural Network Corrector for Enhancing the Stability of Explicit Euler Method in Large Time-Step Regimes: A Lotka–Volterra Case Study"**

The project proposes a **data-driven neural correction strategy** that enhances the stability and accuracy of the explicit Euler method when integrating oscillatory dynamical systems using **large time steps**. The Lotka–Volterra predator–prey model is used as a benchmark problem.

---

## 📌 Motivation

Explicit Euler is computationally cheap but notoriously unstable for oscillatory systems unless very small time steps are used. High-order methods (e.g. Runge–Kutta or Taylor schemes) provide accuracy but at a significantly higher computational cost.

This work explores a hybrid approach:

* Use **Euler with large time steps** as a baseline predictor
* Learn the **local truncation error** using a neural network
* Correct Euler trajectories using the learned residuals

The result is a method that preserves qualitative dynamics (phase portraits) while remaining computationally efficient.

---

## 🧠 Method Overview

1. **Parameter Sampling**
   Multiple combinations of Lotka–Volterra parameters are generated and stored in `ParameterSet.csv`.

2. **Reference Data Generation**
   For each parameter set:

   * A **sixth-order Taylor method** is used as a high-accuracy reference solution
   * An **explicit Euler method** with large time step is used as a low-cost baseline

3. **Residual Learning**
   The neural network is trained to learn the residual:

   r(t) = Taylor(t) - Euler(t)


4. **Neural Corrector**
   The trained network predicts corrections for prey and predator populations, improving Euler stability without reducing the time step.

## ⚙️ Data Generation

The dataset is generated by numerically integrating the Lotka–Volterra system:

dN/dt = N (a − b P)  
dP/dt = P (c N − d)


For each parameter configuration:

* A **Taylor method of order 6** is used as a reference solver
* An **explicit Euler scheme** is used to compute baseline trajectories
* Residuals between both solutions are stored as training targets

The data generation script outputs CSV files of the form:

```
data_h_<Δt>.csv
```

---

## 🧩 Neural Network Architecture

The corrector is a **residual neural network (ResNet)** with:

* Input: system parameters, state variables, time, Euler solution, and engineered Δt features
* Output: correction terms for prey and predator populations

Key characteristics:

* SiLU activation functions
* Residual blocks with Layer Normalization
* Mean Squared Error (MSE) loss on residuals
* Early stopping based on validation error

## 🚀 Training

To train the neural corrector:

```bash
python train_corrector.py
```

The script:

* Loads generated datasets

* Trains the neural network
* Saves the best-performing model based on validation loss
* Plots the training and validation loss curves

## ▶️ How the Code Works

This section explains how each main script in the repository operates and how the full pipeline is executed, from data generation to neural network evaluation.

---

## 1️⃣ Dataset Generation (`DeltaGenerator.py`)

The script `DeltaGenerator.py` is used to generate the dataset employed to train the neural corrector.

**Description**

- The script loads parameter combinations from the file `ParameterSet.csv`.
- For each parameter set:
  - **1000 solution points** are generated.
  - A **sixth-order Taylor method** is used as a high-accuracy reference solution.
  - The **explicit Euler method** is used as the baseline method to be improved.
- A **fixed time step size h (Δt)** is specified by the user.

In the experiments presented in the paper, the following time step sizes were used:

- Δt = 0.5  
- Δt = 0.8  
- Δt = 1.0  
- Δt = 1.1  

Since 100 parameter combinations are used and 1000 points are generated for each one, the resulting dataset contains **100,000 samples**.

**Output**

The script produces a CSV file named: data_h_<Δt>.csv

For example, when Δt = 0.5: data_h_0.5.csv

In addition to the parameters `a, b, c, d, N0, P0`, the dataset includes the following columns:

- `Ntaylor`, `Ptaylor`  
  Sixth-order Taylor reference solutions for prey and predator populations.

- `Neuler`, `Peuler`  
  Explicit Euler solutions for prey and predator populations.

- `residual_N = Ntaylor - Neuler`  
- `residual_P = Ptaylor - Peuler`  

These residuals are used as training targets for the neural network.

---

## 2️⃣ Neural Network Training (`NeuralCorrector.py`)

The script `NeuralCorrector.py` is responsible for training the neural network used to correct the explicit Euler method.

**Description**

- Loads the dataset generated in the previous step (e.g. `data_h_0.5.csv`).
- Performs feature engineering and data normalization.
- Trains a residual neural network to predict the Euler correction terms.
- Applies early stopping based on validation loss.

**Output**

The trained model is saved as: multi_DELTA_resnet_corrector_<Δt>.pth

For example, when Δt = 0.5: multi_DELTA_resnet_corrector_0.5.pth


At the end of the training process, the script also plots the **training and validation loss curves**.

---

## 3️⃣ Evaluation with Unseen Parameters (`RandomValues.py`)

The script `RandomValues.py` is used to evaluate the effectiveness and generalization capability of the trained neural corrector.

**Description**

- The neural network is tested on **parameter values not seen during training**.
- The neural correction is applied to the explicit Euler method.
- The corrected solution is compared against the reference trajectory.
- The **Mean Absolute Error (MAE)** is computed.
- Resulting trajectories are visualized through plots.

**Important Notes**

Before running this script, the user must modify the following variables:

1. Set the correct path to the trained model:  ckpt_path = "/content/multi_DELTA_resnet_corrector_0.5.pth"

2. Ensure that the time step size matches the model being used: h = delta = 0.5

The value of Δt used during evaluation must coincide with the value used during training.

## 📈 Main Results

* Significant stability improvement of Euler for large Δt
* Better qualitative preservation of closed orbits
* Lower long-term error accumulation
* Favorable accuracy–cost trade-off compared to high-order solvers
